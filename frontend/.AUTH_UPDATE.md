# Frontend AuthContext - Updated for NestJS Backend

## Key Changes Made

Your `AuthContext.js` has been completely refactored to match your NestJS backend architecture:

### ✅ What's Aligned with Your Backend:

1. **Login Endpoint**:

   - Sends email/password to `/api/auth/login`
   - Returns `{ accessToken }` (no separate refreshToken - it's httpOnly)
   - Stores accessToken in localStorage
   - Refresh token stored in httpOnly cookie automatically by browser

2. **Signup Endpoint**:

   - Sends email/password to `/api/auth/signup`
   - Returns `{ id, email }`
   - Auto-logs in user after signup

3. **Refresh Token**:

   - POST to `/api/auth/refresh` with `credentials: "include"`
   - Returns new `{ accessToken }`
   - Refresh token in httpOnly cookie sent automatically
   - Auto-refreshes on 401 responses

4. **Logout Endpoint**:

   - POST to `/api/auth/logout` with `credentials: "include"`
   - Clears httpOnly refresh token cookie

5. **Cookie Handling**:
   - All requests use `credentials: "include"`
   - Browser automatically sends/receives httpOnly cookies
   - No manual CSRF token header needed (csurf validates via cookies)

### 🔧 Updated API Calls:

- **login()** - No longer needs refreshToken in response
- **signup()** - Returns { id, email }, then auto-logs in
- **logout()** - Clears tokens from both localStorage and httpOnly cookies
- **doRefreshToken()** - Uses refresh endpoint with credentials
- **apiCall()** - Automatically refreshes token on 401

### ⚠️ Important Notes:

1. **User Endpoint Issue**: The code tries to fetch `/api/users/me` but your controller has `/api/users/:id`. You may need to:

   - Create a `/api/users/me` endpoint that returns current user
   - OR update the login/init code to use a user ID you have

2. **Bearer Token**: All API calls to protected routes use `Authorization: Bearer {token}`

3. **Cookie Scope**: Your refresh token cookie has `path: '/api/auth/refresh'` - make sure this is correct

### 🧪 Next Steps to Test:

1. Restart Next.js dev server: `npm run dev`
2. Try signing up at `/signup`
3. You should see the refresh token cookie in DevTools → Application → Cookies
4. Try logging in at `/login`
5. Check Network tab to see the cookies being sent

### 🐛 If You Get Errors:

- **404 on /api/users/me** → Create this endpoint or adjust the user fetch logic
- **CSRF Still Failing** → Make sure your NestJS CORS allows `credentials: include`
- **Token Not in Cookie** → Verify your login response actually sets the cookie
